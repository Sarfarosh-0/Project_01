# Avengers Endgame Saga 🎬

A static movie showcase website built using **HTML and CSS** that displays movies from the Marvel Cinematic Universe (MCU) in a clean, card-based layout.

This project is created to practice frontend fundamentals such as HTML structure, CSS styling, layout design, and basic UI components.

---

## 🔥 Features

- 🎥 Card-based layout for MCU movies  
- 🖼️ Movie posters with title and short description  
- 🏷️ Genre tags for each movie  
- 🔗 IMDb links for detailed movie information  
- 🧭 Navigation bar and footer section  
- 🎨 Styled using pure CSS (no frameworks)

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
